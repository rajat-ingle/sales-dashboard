# 📊 Sales & Profit Dashboard (Excel)

This interactive dashboard was created using Microsoft Excel and VBA to analyze mock sales and profit data across product categories and regions. The dashboard enables dynamic filtering, performance tracking, and actionable business insights.

---

## 📈 Key Features

- Category-wise sales and profit metrics
- Monthly sales trends and comparison
- Interactive slicers for Region, Product, and Month
- Conditional formatting for KPI tracking
- Visual charts and tables for quick insights

---

## 🛠️ Tools Used

- **Microsoft Excel** (.xlsm)
- VBA Macros (for interactivity)
- PivotTables and PivotCharts
- Data Validation & Conditional Formatting

3. Use the slicers to explore performance by Region, Category, and Month
